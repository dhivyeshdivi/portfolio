## ▶️ Run locally

Open `index.html` in your browser. That's all.

## 📤 Publish on GitHub Pages

1. Create a new repository on GitHub (for example `portfolio`).
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and the `/ (root)` folder, then save.
5. After a minute, your site will be live at `https://your-username.github.io/portfolio/`.

Tip: name the repository `your-username.github.io` to get the shorter address `https://your-username.github.io/`.

## ✏️ Customising

- **Text and projects:** edit `index.html`. The terminal answers in `script.js` (the `commands` object) should match.
- **Email:** change `EMAIL` at the top of `script.js` and the email links in `index.html`.
- **Colours:** change the variables at the top of `style.css`.
- **GitHub and LinkedIn:** add your links to the Contact section in `index.html` once you're ready.
